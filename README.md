# LingoInView Wear — 500 English Flashcards

**Офлайн-игра для Xiaomi Smart Band 10 Pro Ceramic (китайская прошивка Xiaomi Vela).** Никакой авторизации, фонового сервера, синхронизации или изменения прошивки браслета.

![Иконка приложения](src/common/logo.png)

## Что внутри

- **Ровно 500 карточек**: 350 отдельных высокоупотребительных слов и 150 полезных фразовых глаголов/выражений.
- **22 группы**: 7 групп слов (глаголы, люди, время, быт, работа и технологии, качества, обучение) + 15 групп выражений (`GET`, `TAKE`, `LOOK`, `GO`, `COME`, `PUT`, `GIVE`, `MAKE`, `TURN`, `BRING`, `HOLD`, `KEEP`, `SET`, `RUN`, другие).
- На лицевой стороне английское слово; при нажатии — русский перевод, английские синонимы и пример использования. Оборотная сторона прокручивается вертикально.
- Для **неправильных глаголов** — V1/V2/V3 и три коротких предложения с формами. Для соответствующих фразовых глаголов формы изменяются вместе с основным глаголом.
- Две кнопки: **ЗНАЮ / НЕ ЗНАЮ**. Итоги по каждому набору и общая статистика.
- Локальное повторение: правильный ответ сдвигает срок повторения на 1/3/7/14/30/60 дней; неправильный — на 10 минут. В «Повторить слова» берутся просроченные карточки и до 20 новых.
- Результаты хранятся **на самом браслете** через `@system.storage`, запись после каждого ответа.
- Явная кнопка **ВЫХОД ИЗ ИГРЫ**, а также обработчик жеста возврата и системного Back.
- **336×480 px**, минимум изображений и анимаций для экономии памяти/энергии.

## Сборка через GitHub Actions

1. Создайте отдельный репозиторий на GitHub (например, `lingoinview-wear`).
2. Распакуйте ZIP проекта и загрузите **все файлы в корень** репозитория, включая `.github/workflows/release.yml`.
3. Сделайте коммит в ветку `main`.
4. Откройте вкладку **Actions → Build LingoInView Wear RPK**. Дождитесь зелёной сборки.
5. В результатах job скачайте artifact `LingoInView-Wear-Band10Pro-RPK` — в нём файл `LingoInView-Wear-Band10Pro.rpk`. При пуше в `main` автоматически создаётся и версия в **Releases**.
6. Установите `.rpk` через **AstroBox → Quick Apps → Install RPK** на уже подключённый браслет.

**Важно:** проект не содержит готовой прошивки. Создаётся приложение `.rpk` с **отладочной подписью** Xiaomi. Работоспособность на реальном Smart Band 10 Pro Ceramic **пока не проверена**, даже если CI успешно соберёт пакет. Не перепрошивайте браслет, не удаляйте pairing в Mi Fitness и не используйте factory reset для установки приложения. При сбое удаляйте **только приложение**.

## Локальная сборка (Mac / Linux / Windows)

Нужны Node.js 20+, Python 3 и доступ к npm:

```bash
python3 scripts/generate_data.py
npm install
npm run check
npm test
npm run build
```

`aiot-toolkit` собирает RPK в `dist/`. Команда сборки такая же, как в уже существующем проекте `runner-smart-band-10-pro`.

## Веб-демо

Откройте `preview/index.html` в браузере. Оно работает офлайн, содержит те же 500 карточек и сохраняет результаты в **localStorage браузера**. Для установки на браслет необходимо собирать RPK; веб-демо не является эмулятором Vela.

## Редактирование слов

`data/words.tsv` и `data/phrases.tsv` — исходники карточек. Формат:

```text
english word|русский перевод|synonym 1,synonym 2|Original English usage sentence.
```

После изменений выполните `python3 scripts/generate_data.py`. Скрипт проверяет точное количество 350 + 150, отсутствие дублей, наличие переводов/примеров, генерирует `src/common/cards.js`, `src/common/groups.js` и данные веб-демо. **При добавлении новых неправильных глаголов** внесите формы и примеры в `scripts/generate_data.py` (словарь `IRREGULAR`/`VERB_EXAMPLES`).

## Частотность и происхождение контента

Подборка составлена вручную с опорой на частотные леммы из:

- [New General Service List / NGSL](https://www.newgeneralservicelist.com/)
- [SUBTLEX-US — movie subtitle frequencies](https://github.com/words/subtlex-word-frequencies)
- [PHaVE / Liu — frequency-based phrasal verb lists](https://gist.github.com/Pernath1200/26a8f160ba0ee4fe1519878cb0b90346)

**Это учебная выборка** частотных и полезных слов, а не опубликованный точный список «первые 350 + первые 150» с единым числовым рейтингом. Из всех корпусов были приоритетно выбраны слова с самостоятельным лексическим значением (без ряда артиклей и служебных слов), а также выражения, удобные для изучения. Русские переводы, синонимы и английские предложения отредактированы/написаны для проекта; исходные массивы словарных статей или защищённые чужие примеры не копировались. При использовании готовых сторонних корпусов в будущем проверяйте отдельные лицензии.

## Функциональные ограничения

- Отсутствует синхронизация с Chrome LingoInView, iOS/Android PWA и сервером — это специально офлайн-MVP.
- Прогресс хранится только на браслете; **удаление приложения или сброс браслета может уничтожить данные**.
- В тестах проверены 500 карточек, логика V1/V2/V3, сохранение и возврат в меню. **Физическое устройство и отображение кириллицы на конкретной CN-прошивке не тестировались.**
- На более старой / глобальной прошивке сторонние RPK могут не устанавливаться.
